# ArchUnpack (批量加密压缩包解压工具)

ArchUnpack 是一个专为 Windows 设计的现代化、高性能的批量压缩包解压工具。它支持嵌套压缩包的递归解压、多密码字典暴力尝试、智能分卷合并以及魔数伪装识别。

## ✨ 核心特性

- **支持多格式解压**：原生支持 `.7z`, `.zip`, `.rar`, `.tar`, `.tar.gz`, `.tar.bz2`, `.tar.xz`。
- **智能密码字典解压**：遇到加密压缩包时，会自动从指定的密码本 (`passwords.txt`) 中逐行尝试，并将成功的密码提前，增加后续任务的命中率。
- **深度递归嵌套解压**：支持解压压缩包内嵌的压缩包，支持设定最大递归深度，并将“套娃”彻底解开。
- **全自动防呆清理**：
  - 支持解压成功后**自动删除中间生成的垃圾嵌套压缩包**。
  - 支持解压成功后**自动删除源压缩包**（需手动勾选开启），彻底释放磁盘空间。
  - 遇到密码错误/中途失败的压缩包，自动进行临时文件清理，**绝不在输出目录残留垃圾文件**。
- **伪装文件识别与分卷合并**：通过文件头魔数 (Magic Number) 识别被恶意修改后缀的压缩包；自动识别分卷压缩包（如 `.001`, `.z01`, `part1.rar` 等）并一次性合并解压。
- **高性能多线程与防死锁设计**：
  - 基于线程池调度，默认针对机械硬盘优化并行度（限制最高并发），防止硬盘 IO 拥堵。
  - 深度整合底层 `7z.exe` 和 `WinRAR`，解决在遇到错误密码时卡死系统的问题（瞬间抛出错误并重试）。
- **GUI 与 CLI 双操作模式**：提供优雅且实时显示解压进度的现代 Tkinter 图形界面，同时支持纯命令行运行模式以供脚本调用。

## 🚀 安装与依赖

### 1. 环境要求
- **操作系统**：Windows 10/11
- **Python 版本**：Python 3.10+
- **系统组件建议**：建议系统中已安装 [7-Zip](https://www.7-zip.org/) 或 [WinRAR](https://www.win-rar.com/)，程序将自动检测其路径并进行性能加速调用。

### 2. 安装步骤
克隆或下载本仓库代码后，安装依赖项：
```bash
pip install -e .
# 或直接安装 requirements
pip install py7zr rarfile pyzipper
```

## 💻 使用方法

### 图形界面 (GUI) 模式
推荐普通用户使用图形界面进行交互：
```bash
python -m archunpack.gui
```
**操作指南**：
1. **源文件夹/文件**：选择你需要解压的目录，程序会自动扫描里面所有的压缩包。
2. **输出文件夹**：解压出的文件存放位置。
3. **密码本 (可选)**：选择一个 `.txt` 文本文件，里面每一行写一个可能的密码。遇到加密文件时程序会自动尝试。
4. **高级选项**：
   - **删除中间文件**：处理多层嵌套解压时，是否把解开的中间层文件删掉。
   - **删除最外层原始压缩包**：解压成功后，自动帮你把原来的压缩包删掉以腾出空间。
   - **最大嵌套层级**：防止无限循环套娃，默认 5 层。
5. 点击**开始执行任务**即可！

### 命令行 (CLI) 模式
适合需要后台自动化处理或脚本调用的极客用户：
```bash
python -m archunpack.cli D:\Path\To\Source D:\Path\To\Output -p D:\Path\To\passwords.txt
```

**高级参数**：
```bash
--max-depth 5         # 最大递归解压深度（默认 5）
--no-delete           # 不删除解压出来的嵌套中间层压缩包
--delete-source       # 成功解压后删除原始的最外层压缩包
--overwrite-mode skip # 遇到同名目录时的处理策略：skip（跳过）, overwrite（覆盖）, rename（重命名）
--threads 4           # 并发线程数，设置为 0 时根据 CPU 和硬盘自动优化（推荐）
```

## 🛠️ 项目架构

- `gui.py` / `cli.py`: 图形与命令行入口。
- `scanner.py`: 扫描器，负责智能归类分卷文件、提取魔数、生成任务。
- `extractor.py`: 核心解压调度器，负责密码尝试循环、安全提取及临时残缺文件清理。
- `task_queue.py`: 多线程并发调度池。
- `engines/`: 具体解压引擎的实现，自动按最优策略在 `pyzipper`, `py7zr`, `zipfile`, `7z.exe`, `WinRAR.exe` 之间无缝降级与切换。
